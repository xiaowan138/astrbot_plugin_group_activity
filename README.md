# astrbot_plugin_group_activity

**AstrBot 群活跃度统计插件**：自动记录群聊发言，提供排行榜、个人活跃档案与活跃时段分析。

</div>

> ⚠️ **开发中声明**：本插件仍在开发中，功能尚未完全稳定，可能存在 bug 或不兼容问题。使用中遇到问题欢迎提 [Issue](https://github.com/xiaowan138/astrbot_plugin_group_activity/issues)，也欢迎反馈改进建议。数据安全起见，重要群的统计数据请定期备份 `group_activity.db`。

## 功能

- **自动记录**：监听所有群聊消息，按群、按人、按天、按小时聚合存储（机器人自己的消息不会计入）。
- **发言排行榜**：支持 今天 / 昨天 / 本周 / 上周 / 本月 / 历史总计 六个维度，显示每人消息数和全群消息总数。
- **个人活跃档案**：查看自己某段时间的发言数、全群排名、本周与历史总量，以及最常活跃的时段。
- **分群开关**：每个群可单独开启/关闭统计，管理员可一键清零本群数据。
- **零外部依赖**：数据全部存放在本地 SQLite，不依赖任何外部 API。

## 安装

1. 将整个 `astrbot_plugin_group_activity` 文件夹放入 AstrBot 的 `data/plugins/` 目录（或通过 WebUI「插件管理 → 从 GitHub 安装」填入本仓库地址）。
2. 重启 AstrBot 或在 WebUI 中重载插件。
3. 首次加载会自动建库，数据文件位于插件数据目录 `group_activity.db`。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/活跃 [范围]` | 查看本群发言排行榜，范围可省略（默认今天） |
| `/我的活跃 [范围]` | 查看个人活跃档案 |
| `/活跃设置 开启\|关闭\|状态` | 管理员开启/关闭本群统计 |
| `/活跃设置 清零 确认` | 管理员清空本群全部数据（需二次确认） |

范围支持：`今天` `昨天` `本周` `上周` `本月` `总计`。

示例：

```
/活跃
/活跃 本周
/活跃 总计
/我的活跃 本周
```

## 配置

在 WebUI 插件配置页修改：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `top_n` | 10 | 排行榜显示人数 |
| `default_enabled` | true | 新群是否默认开启统计 |
| `count_command` | true | 是否把 `/xxx` 指令消息也计入统计 |

## 权限说明

`/活跃设置` 需要 AstrBot 的管理员权限（WebUI「配置 → 管理员 ID」中设置的用户），普通群成员无法操作。

## 常见问题

- **排行榜里显示「用户XXXX」**：该平台/该时刻没有提供发送者昵称，插件会用 ID 后四位兜底显示，一旦收到过昵称就会自动更新。
- **统计从什么时候开始？** 只统计插件加载之后收到的消息，历史聊天记录无法回溯。
- **关闭统计后数据会丢吗？** 不会，关闭只是暂停记录，历史数据保留；`/活跃设置 清零 确认` 才会删除。
- **私聊会统计吗？** 不会，插件只监听群聊消息。

## 数据表结构

数据库中共 5 张表：`total_stat`（历史总量）、`daily_stat`（按天）、`hour_stat`（按小时）、`user_name`（昵称缓存）、`group_conf`（分群开关），可用任意 SQLite 工具直接查看。
