# astrbot_plugin_group_activity

**AstrBot 群活跃度统计插件**：自动记录群聊发言，提供排行榜、个人活跃档案、潜水榜、进步榜、趋势分析与 CSV 导出。

</div>

> ⚠️ **开发中声明**：本插件仍在开发中，功能尚未完全稳定，可能存在 bug 或不兼容问题。使用中遇到问题欢迎提 [Issue](https://github.com/xiaowan138/astrbot_plugin_group_activity/issues)，也欢迎反馈改进建议。数据安全起见，重要群的统计数据请定期使用 `/活跃导出` 或手动备份 `group_activity.db`。

## 功能

- **自动记录**：监听所有群聊消息，按群、按人、按天、按小时聚合存储（机器人自己的消息不会计入）。
- **发言排行榜**：支持 今天 / 昨天 / 本周 / 上周 / 本月 / 上月 / 近7天 / 近30天 / 历史总计，以及自定义日期范围。
- **个人活跃档案**：查看某段时间的发言数、全群排名、本周与历史总量、连续活跃天数，以及该时段最常活跃的小时。
- **潜水榜**：找出超过 N 天没有发言的成员。
- **进步榜**：对比本周与上周，显示发言增量最大的成员和新星。
- **活跃趋势**：查看最近 N 天每天的消息量，文字柱状图展示。
- **CSV 导出**：管理员可导出本群指定范围的完整统计，便于备份或二次分析。
- **分群开关**：每个群可单独开启/关闭统计，管理员可一键清零本群数据。
- **数据安全**：新版 AstrBot 下数据存放在 `data/plugin_data/`，更新插件不会丢失；首次启动会自动迁移旧版插件目录里的数据库。
- **无外部 API 依赖**：数据全部存放在本地 SQLite，仅依赖 `aiosqlite`。

## 安装

1. 将整个 `astrbot_plugin_group_activity` 文件夹放入 AstrBot 的 `data/plugins/` 目录（或通过 WebUI「插件管理 → 从 GitHub 安装」填入本仓库地址）。
2. 重启 AstrBot 或在 WebUI 中重载插件。
3. 首次加载会自动建库。新版 AstrBot 的数据文件位于：

   ```
   data/plugin_data/astrbot_plugin_group_activity/group_activity.db
   ```

   旧版 AstrBot 或无法获取插件数据目录时，会回退到插件目录下的 `data/group_activity.db`；升级到新版后会自动迁移旧库。

## 指令

| 指令 | 说明 |
| --- | --- |
| `/活跃 [范围]` | 查看本群发言排行榜，范围可省略（默认今天） |
| `/我的活跃 [范围]` | 查看个人活跃档案 |
| `/潜水榜 [天数]` | 查看超过 N 天未发言的成员（默认取配置 `dive_days`） |
| `/进步榜` | 本周相比上周的发言进步榜 |
| `/活跃趋势 [天数]` | 最近 N 天每日消息趋势（1~30 天，默认 7） |
| `/活跃导出 [范围]` | 导出本群统计数据为 CSV（管理员） |
| `/活跃设置 开启\|关闭\|状态` | 管理员开启/关闭本群统计，或查看统计概览 |
| `/活跃设置 清零 确认` | 管理员清空本群全部数据（需二次确认） |

范围支持：`今天` `昨天` `本周` `上周` `本月` `上月` `近7天` `近30天` `总计`，或自定义 `2026-11-01~2026-11-13`。

示例：

```
/活跃
/活跃 本周
/活跃 近30天
/活跃 2026-11-01~2026-11-13
/我的活跃 本周
/潜水榜 7
/进步榜
/活跃趋势 14
/活跃导出 本月
```

## 配置

在 WebUI 插件配置页修改：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `top_n` | 10 | 排行榜显示人数（1~50） |
| `default_enabled` | true | 新群是否默认开启统计 |
| `count_command` | false | 是否把指令消息也计入统计 |
| `dive_days` | 7 | 潜水榜默认天数（1~365） |
| `timezone_offset` | 0 | 时区偏移，0 表示跟随服务器时区，北京时间填 8 |

## 权限说明

- `/活跃设置` 和 `/活跃导出` 需要 AstrBot 的管理员权限（WebUI「配置 → 管理员 ID」中设置的用户），普通群成员无法操作。
- 排行榜、个人档案、潜水榜、进步榜、趋势对所有群成员开放。

## 常见问题

- **排行榜里显示「用户XXXX」**：该平台/该时刻没有提供发送者昵称，插件会用 ID 后四位兜底显示，一旦收到过昵称就会自动更新。
- **统计从什么时候开始？** 只统计插件加载之后收到的消息，历史聊天记录无法回溯；`/活跃设置 状态` 可以查看统计起始日期。
- **关闭统计后数据会丢吗？** 不会，关闭只是暂停记录，历史数据保留；`/活跃设置 清零 确认` 才会删除。
- **私聊会统计吗？** 不会，插件只监听群聊消息。
- **指令消息会计入活跃度吗？** 默认不计入（`count_command` 为 false）；如果希望计入，可在配置中打开。
- **为什么「常活跃时段」没有旧数据？** 按范围统计小时段需要日期维度，该功能从 v1.1.0 开始记录；历史总计仍可查看旧数据。
- **更新插件后数据会丢吗？** 新版会存放在 `data/plugin_data/`，更新不会丢；从旧版升级时会自动迁移插件目录里的旧库。仍建议定期备份。
- **时间和实际差 8 小时？** Docker 等环境服务器可能是 UTC，把 `timezone_offset` 设为 `8` 即可按北京时间统计。

## 数据表结构

数据库中共 6 张表：

| 表 | 说明 |
| --- | --- |
| `total_stat` | 历史总量、最后发言时间 |
| `daily_stat` | 按天统计 |
| `hour_stat` | 按小时统计（历史总计） |
| `daily_hour_stat` | 按天 + 小时统计（范围查询） |
| `user_name` | 昵称缓存 |
| `group_conf` | 分群开关 |

可用任意 SQLite 工具直接查看。

- 新增：上月、近7天、近30天、自定义日期范围。
- 新增：`/潜水榜`、`/进步榜`、`/活跃趋势`、`/活跃导出`。
- 新增：个人档案显示连续活跃天数；排行榜显示每人占比。
- 新增：`timezone_offset`、`dive_days` 配置；`top_n` 限制在 1~50。
